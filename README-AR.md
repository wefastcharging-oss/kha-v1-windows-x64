# kha v1.2 — نسخة ويندوز

النسخة الحالية مبنية حول القوائم المطلوبة فقط:

- الرئيسية
- إضافة الألعاب
- مكتبتي
- Token Tools — حساب محلي فقط
- Online Fix
- الحساب
- الإعدادات

## الوظائف الحالية

- البحث عن الألعاب بالاسم أو App ID وإضافتها إلى المكتبة المحلية.
- استيراد ملفات Lua وManifest التي يملكها المستخدم، من دون تنفيذ سكربتات Lua داخل التطبيق.
- حفظ اسم حساب محلي وSteamID64 على الجهاز فقط، من دون طلب كلمة مرور أو رمز Steam.
- فتح اللعبة المثبتة عبر Steam أو فتح صفحتها الرسمية.
- نسخ ملفات الحفظ واستعادتها مع نقطة أمان تلقائية.
- فحص مجلدات التطبيق وSteam وإصلاح البنية المحلية الناقصة.
- تصدير المكتبة واستيرادها محليًا.

## ما سيأتي مع ربط الخادم

- مستودع خاص لملفات المستخدم المرخّصة مع التحقق من الملكية.
- مزامنة اختيارية للحساب والمكتبة بين الأجهزة.
- حالة واضحة للتنزيل والتحديث من المصدر الخاص.

Token Tools لا يولّد رموز DRM ولا يستعير رموز حسابات أخرى. صفحة Online Fix لا تنزّل cracks أو تتجاوز ترخيص Steam؛ وهي حاليًا تشغّل النسخة المثبتة رسميًا وتفتح صفحة المتجر.

## التشغيل

شغّل `kha.exe` من المجلد الرئيسي مع إبقاء مجلد `resources` وبقية الملفات بجانبه. التطبيق غير موقّع رقميًا؛ لا تعطل برنامج الحماية لتشغيله.

## الاختبارات

آخر فحص محلي نجح في اختبارات النسخ والاستعادة، الفحص والإصلاح، استيراد ZIP، وتصفية مكونات Steam المساعدة. لم يُربط بعد بخادم إنتاج، ولم يُختبر على حساب Steam حقيقي.
